# Rent a Car - Fullstack Application

## Backend
Aplicação Java Spring Boot que gerencia operações de aluguel de veículos, incluindo:
- Cadastro e listagem de clientes
- Controle de aluguéis (criação, listagem e devolução)
- Estratégias de cálculo de preços (standard e premium)
- Integração com feriados brasileiros para cálculo de diárias
- Repositórios em memória para persistência

## Frontend  
Aplicação React com Vite que fornece interface para:
- Dashboard com visão geral das operações
- Cadastro e listagem de clientes
- Controle de aluguéis (criação e listagem)
- Geração de relatórios
- Integração com backend via API REST
